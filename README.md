# Планер

Календарь, идеи, заметки и документы: Личное, КАДИС, Найдём предков.
Записи и файлы документов синхронизируются через приватный репозиторий `planer-data` (настраивается во вкладке «Настройки»).
Напоминания, утренняя сводка и газета приходят в Telegram (workflow `.github/workflows/remind.yml`).
